# Amostras sintéticas

Os arquivos de emendas e eleições nesta pasta são **inteiramente fictícios**, com cabeçalhos compatíveis com os adaptadores. Não são dados sobre candidatos, empresas ou sanções reais. Servem para avaliação reprodutível sem rede. O campo de cobertura do lote usa `DEMONSTRACAO` quando carregados pelo comando demo.

O modo offline combina essas amostras com o recorte CEAP real já existente em `tests/dados/ceap_amostra.csv`. Não use um banco de demonstração para concluir algo sobre pessoas reais.
